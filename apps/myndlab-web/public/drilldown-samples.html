Drilldown patterns for /features & /solutions

Each pattern below shows the same four Myndlab features (AI Code Gen, Voice Brainstorming, Design DNA, Version History) rendered with a different interaction. Click cards / tabs / arrows to test feel. All four are fixed-screen — no scrolling for the user.

Pattern A
Card grid + side drawer
Recommended

Click any card. Drawer slides in from the right with the deep-dive. ESC or × closes it back to the grid. Best for 4-8 items where you want fast comparison without losing context.

Card grid + sub-routes

Pattern C
Tabs at the top
~5 items max

Click a tab. Content swaps below, no overlay. Always visible, no extra click. Caps at ~5-6 items before tabs scroll horizontally.

Pattern D
Carousel / slider
One at a time

Arrow keys / buttons / swipe. One full deep-dive at a time. Most fixed-screen-pure, but slower to scan — user can't see all options at once.

1 / 4
My pick: Pattern A — Card grid + side drawer. Best fit for /features (7 items) and /solutions (5 items): user sees the full lineup at a glance, drilling into any item is one click and one ESC away. Pattern B is the better long-term play if you want individual URLs for SEO (worth doing later, when porting to the real Rust repo). Pattern C caps at 5 items so it limits Features. Pattern D is most "fixed-screen" but worst for scanning.
